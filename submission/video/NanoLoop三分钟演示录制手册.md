# 先定故事，再按录制键

三分钟很短，不能把系统菜单从头念一遍。评委最需要看到的是一条清楚的因果链：

> 原始 SEM 图像里混有仪器信息，人工统计慢且口径不一；NanoLoop 先找出有效成像区和尺度，再逐图选择模型，计算可复核指标，最后让科研助手说明结果、证据和下一步验证。

建议成片长度 **2 分 48 秒至 2 分 55 秒**，不要卡在 2:59。主版本按 2:52 设计，给片头、转场或语速误差留出余量。

## 录制前必须准备的两项任务

1. **现场任务 A：** 首页已准备三张原始 SEM 图，录制时现场点击上传并创建任务，用来证明输入流程真实。
2. **预完成任务 B：** 相同图像已经完成模型运行，结果页、质量、助手和导出都可立即打开。

三分钟内模型是否跑完取决于电脑，不能赌。切换到任务 B 时，旁白必须诚实说“为了在三分钟内完整展示，我们打开同一组图像预先完成的运行”。这不是伪装实时结果，而是把有限时间留给可审查的科学链条。

## 画面准备

- 屏幕分辨率设为 1920×1080；Retina Mac 选择“看起来像 1920×1080”附近的缩放。
- 浏览器缩放设为 80% 或 90%，确保左侧导航、主结果和右侧助手同时可见。
- 隐藏书签栏，关闭无关标签页、微信、邮件、系统通知和桌面敏感文件。
- 只保留两个 NanoLoop 标签页：任务 A 首页、任务 B 已完成结果。
- 鼠标速度调慢一档，点击后停 0.5 秒，让评委看清。
- 麦克风离嘴约 15–20 cm。先录 10 秒试听，确认没有喷麦和空调噪声。
- 关闭自动锁屏和系统更新；电源接通。
- 录制机必须提前启动 Ollama，并用 `NANOLOOP_ENABLE_LOCAL_QWEN=1` 启动 NanoLoop。正式录制前确认助手显示“Qwen 已连接”，再生成一次批量报告；报告页应显示“Qwen 已参与”，并包含所选视野的识别叠加图。

# 2. 逐镜操作和逐字旁白

## 镜头 1｜0:00–0:12

**画面：** 深色或白色简洁片头，标题“NanoLoop：从显微图像到实验洞察”，副标题“纳米颗粒图像识别工具开发小组”。第 3 秒淡入一张原始 SEM 图。

**旁白：**

“一张 SEM 图像看起来直观，但把它变成可信的颗粒统计，往往要在裁图、量尺度、选算法和表格之间反复切换。NanoLoop 想解决的，就是这段最容易丢失实验上下文的工作。”

## 镜头 2｜0:12–0:28

**画面：** 首页，点击添加图像，选择三张图。任务名称保持默认或填写“BaCo 批量形貌分析”，点击“自动分割 3 张图像”。

**旁白：**

“我们先上传三张原始图像。第一次使用只需要选图，任务名、材料名和实验条件都可以后补；批量图像会进入同一个可追溯工作区。”

## 镜头 3｜0:28–0:45

**画面：** 任务概览。鼠标先停在“比例尺/物理尺度”，再停在探测器、加速电压和有效成像区。若画面能看到底部信息栏，轻轻框一下。

**旁白：**

“系统自动识别 SEM 底部的比例尺和仪器信息，并把信息栏排除在分割区域之外。没有信息栏时保留全图；尺度读不出来时只报告像素单位，不猜纳米数值。”

## 镜头 4｜0:45–0:58

**画面：** 点击“局部区域”。在右侧列表点击 ROI 1，拖动画布中的框，再拖一次右下角控制点，点击保存。

**旁白：**

“如果只关心局部，可以画 ROI，也可以跳过。多个框从右侧列表选择，画布只编辑当前框；每次保存形成新版本，旧运行不会被后来改框悄悄覆盖。”

## 镜头 5｜0:58–1:15

**画面：** 点击“开始分析”。先点击左侧图像 1，指向推荐模型；再点击图像 2，指向另一推荐或人工改选；把模型卡中的适用范围和科学状态扫过。

**旁白：**

“批量处理并不意味着所有图都用同一个模型。NanoLoop 根据有效区域、图像特征和模型证据逐图推荐；研究者仍可查看模型卡后确认，或为了对照同时运行多个模型。”

## 镜头 6｜1:15–1:24

**画面：** 点击开始运行，进度页出现后，从浏览器标签切到预完成任务 B。

**旁白：**

“运行会在后台记录真实阶段。为了在三分钟内完整展示，我们现在打开同一组图像预先完成的运行。”

## 镜头 7｜1:24–1:48

**画面：** 结果页先停在顶部质量提示；切换“原图”与“识别叠加”；向下到指标卡，指向颗粒数、等效直径、覆盖率和数密度。不要快速来回闪。

**旁白：**

“结果页先给质量结论，再给数字。识别叠加、实例表和汇总统计来自同一份后处理结果。尺度可靠时输出等效直径、覆盖率和数密度；有边界颗粒或异常分布时，警告会和结果一起保留。”

## 镜头 8｜1:48–2:05

**画面：** 勾选多个已完成运行，生成批量报告；展示均值、四分位数、质量分层、异常视野和多张识别叠加图。短暂停在“Qwen 已参与”，随后把注意力移回实验结果。

**旁白：**

“同一图像可以比较模型，不同图像可以形成批量汇总。报告纳入每个所选视野的统计和识别图，由本地 Qwen 依据已验证证据整理结果解读；所有数字仍来自确定性计算。”

## 镜头 9｜2:05–2:30

**画面：** 右侧科研助手输入预先练熟的问题：

`概括当前结果，说明最重要的质量限制，并给出下一步验证建议。`

展示回答，再点开“证据/来源”入口。若 Qwen 响应需要几秒，可提前把问题发送完，剪掉纯等待时间，但不能拼接另一任务的回答。

**旁白：**

“助手首先能自然对话；当问题涉及当前实验，它才调用确定性数据工具。材料问题可检索本地知识库和在线题录。Qwen 负责解释，不负责编造颗粒数；回答会同时给出数据引用、来源和限制。”

## 镜头 10｜2:30–2:42

**画面：** 点击“导出当前运行”或报告下载，显示下载成功；短暂展示导出内容列表或系统里的来源/运行身份。

**旁白：**

“导出包把原图摘要、ROI、模型、参数、质量、实例 CSV 和报告放在一起。别人拿到的不是一张结果截图，而是一条能复核的分析记录。”

## 镜头 11｜2:42–2:52

**画面：** 结尾页，左侧一句话，右侧团队名。可使用工作流图的缩略版。

**旁白：**

“从 SOEC 阴极材料筛选出发，NanoLoop 让显微图像真正进入可比较、可追溯的实验数据闭环。我们是纳米颗粒图像识别工具开发小组。”

# 4. macOS：QuickTime 精确步骤

**步骤 1：** 打开“系统设置 → 通知”，临时开启“勿扰模式”。

**步骤 2：** 打开“QuickTime Player”。

**步骤 3：** 菜单栏选择“文件 → 新建屏幕录制”。也可以按 `Command + Shift + 5`。

**步骤 4：** 选择“录制整个屏幕”。点击“选项”，麦克风选择实际使用的麦克风，存储位置选择桌面，打开“在录制中显示鼠标点按”。

**步骤 5：** 点击“录制”，等 2 秒再开始片头。

**步骤 6：** 录完后点击菜单栏停止按钮。QuickTime 打开视频后，选择“编辑 → 修剪”，去掉开头和结尾多余等待。

**步骤 7：** 选择“文件 → 导出为 → 1080p”。文件名：

`NanoLoop三分钟演示视频_纳米颗粒图像识别工具开发小组.mp4`

如果 QuickTime 导出为 `.mov`，可用随系统兼容的视频编辑器或 `ffmpeg` 转为 H.264 MP4。提交前在另一台电脑完整播放一次。

# 5. Windows：截图工具 + Clipchamp 精确步骤

## 5.1 录屏

**步骤 1：** 打开“设置 → 系统 → 通知”，开启“请勿打扰”。

**步骤 2：** 在开始菜单打开“截图工具（Snipping Tool）”。

**步骤 3：** 切换到摄像机图标，点击“新建”。

**步骤 4：** 框选整个浏览器区域，确认麦克风已启用，点击开始。

**步骤 5：** 录完点击停止并保存 MP4。

如果系统截图工具没有录屏功能，可按 `Win + G` 打开 Xbox Game Bar，使用“捕获”组件录制当前浏览器窗口；录制前用“音频”组件确认麦克风电平。

## 5.2 剪辑

**步骤 1：** 打开 Microsoft Clipchamp，新建 16:9 视频。

**步骤 2：** 导入录屏，拖到时间线。

**步骤 3：** 只剪掉等待、口误和标签切换空白，不要把不同任务的数字拼成同一次运行。

**步骤 4：** 片头和结尾各保持 2–3 秒；标题字体使用微软雅黑，正文不小于 36 px。

**步骤 5：** 导出 1080p MP4，检查总时长小于 3:00。

# 6. Ubuntu：OBS Studio 精确步骤

**步骤 1：** 安装 OBS：

```bash
sudo apt update
sudo apt install -y obs-studio
```

**步骤 2：** 打开 OBS，首次向导选择“仅优化录像，不直播”，基础画布与输出分辨率都设为 1920×1080，帧率 30。

**步骤 3：** 在“来源”区域点击 `+`，Wayland 选择“屏幕捕获（PipeWire）”，X11 选择“显示器捕获”。选择浏览器所在屏幕。

**步骤 4：** 在“音频混音器”确认“麦克风/辅助音频”有绿色电平；把“桌面音频”静音，避免通知声。

**步骤 5：** “设置 → 输出 → 录像”，格式选择 MKV，编码器选择硬件 H.264（若可用）或 x264。

**步骤 6：** 点击“开始录制”。完成后点击“停止录制”。

**步骤 7：** 选择“文件 → 录像转封装”，把 MKV 转为 MP4。转封装不会重新编码，速度很快。

# 7. 剪辑与画面规则

- 最多使用 3 次硬切：片头到首页、运行进度到预完成结果、结果到结尾。
- 不使用炫目的旋转、粒子或故障特效；科研界面本身就是主角。
- 关键数字只放一层字幕，不把整段旁白铺满画面。
- 字幕颜色使用深灰和 NanoLoop 蓝；警告沿用系统琥珀色，不用大红字制造紧张感。
- 鼠标移动到目标后停顿，再说对应内容；不要一边快速滚动一边念指标。
- 响应等待超过 2 秒可以剪短，但保留点击与最终同一请求的回答。
- 不展示 GitHub、终端构建日志或长代码；部署能力用一句话和 Docker 标识收束即可。

# 8. 录制失败时的备用方案

| 问题 | 立即处理 |
|---|---|
| 模型运行太慢 | 使用预完成任务 B，并保留现场点击启动的镜头 |
| Qwen 临时不响应 | 暂停录制，确认 Ollama 和精确模型 tag，重新运行启用 Qwen 的启动脚本；报告镜头不能用模板或旧报告冒充本次生成 |
| 在线文献不可用 | 展示本地知识引用和明确的在线能力状态，不伪造联网 |
| 页面比例不合适 | 浏览器缩放调到 80%，不要用后期强行拉伸 |
| 口误但画面正确 | 从上一句停顿处重录；剪辑时保留自然呼吸 |
| 总时长超过 3 分钟 | 先删等待，再缩短模型卡和批量报告镜头，不删科学边界 |
