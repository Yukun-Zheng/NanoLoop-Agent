建议阅读顺序

第一步：打开“01_智能体设计文档/NanoLoop智能体设计文档.pdf”。
第二步：按电脑系统打开“02_Docker部署包/NanoLoop_Docker部署与使用手册.pdf”对应章节。
第三步：评委电脑已安装 Docker 时，进入“02_Docker部署包/NanoLoop-Agent”，双击对应系统的“启动NanoLoop”脚本。
第四步：浏览器打开 http://127.0.0.1:3000，使用“示例输入”中的图片完成 90 秒快速验收。
第五步：打开“03_三分钟演示视频”中的 MP4；若视频尚未放入，请按同目录录制手册完成录制。

三项正式材料

1. 智能体详细设计文档：PDF 和 DOCX；
2. Docker 部署包：完整源码、模型资产、跨系统启动脚本、部署手册与可选 linux/amd64 离线镜像；
3. 三分钟以内演示视频：H.264 MP4，另附分镜与录屏手册。

说明

- 评委机默认不启动 Qwen，也关闭在线检索；科研助手采用本地证据摘录模式，确定性图像分析、质量审查和导出均可用。
- Qwen/Ollama 与在线研究是演示机可选增强，配置方法见部署手册，不是基础验收前提。
- Docker 离线镜像约 1 GB，因此可能与邮件主压缩包分开交付；文件名和 SHA-256 会列在 SHA256SUMS.txt。
- 系统默认只绑定 127.0.0.1，不向局域网或公网开放。
- 演示中的模型指标均保留适用范围；“可运行”不等于“已在所有材料上完成科学泛化”。
